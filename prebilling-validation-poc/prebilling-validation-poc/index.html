Pre-billing invoice validation — POC

Two mock systems over one shared dataset. POMS is the source of truth; Workday ERP holds the pre-billing invoice. A handful of records are deliberately wrong so a validation agent has something to catch.

Target system

Workday ERP

Find Open Customer Invoices - OTC: invoice grid and the View Customer Invoice detail page with invoice, additional and amount information plus invoice lines.

 Source of truth

POMS — Order Management

Order list with search, and the order detail page with overview, price information, order lines, deliveries and events.

Join key: workday.sales_order = poms.order_no. GitHub Pages serves these files with Access-Control-Allow-Origin: *, so you can call them from a notebook, a FastAPI service, or another browser app.

Calling it from Python

import requests

BASE = "https://<your-user>.github.io/<your-repo>"

invoices = requests.get(f"{BASE}/api/invoices.json").json()["data"]
orders   = {o["order_no"]: o for o in requests.get(f"{BASE}/api/orders.json").json()["data"]}

for inv in invoices:
    po = orders.get(inv["sales_order"])
    if not po:
        print(inv["invoice_number"], "no matching order in POMS")
        continue
    if round(inv["total_invoice_amount"], 2) != round(po["grand_total_price"], 2):
        print(inv["invoice_number"], "amount mismatch",
              inv["total_invoice_amount"], "vs", po["grand_total_price"])
